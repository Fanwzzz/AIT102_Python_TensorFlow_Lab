# AIT102_Python_TensorFlow_Lab

这是我学习 **AIT102 Python and Tensorflow Programming 2026/09** 的练习仓库，主要用于 Python 基础、NumPy、TensorFlow 和简单的科学计算实验。

项目用 `uv` 管理独立的 Python 3.11 环境。安装依赖后，可在 VS Code 中选择本项目的 `.venv` 解释器运行 `exercise/` 下的练习：

```bash
uv sync --locked
uv run --locked python exercise/lab01/ex01.py
```

课程幻灯片、作业原题、个人 Notebook、环境检查脚本和本机 VS Code 配置仅保留在本地，不随仓库发布。课程资料的权利属于各自权利人；本仓库不授予这些资料的转载许可。
